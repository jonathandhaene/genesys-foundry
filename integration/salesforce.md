# Salesforce Integration

## Integration Overview

Salesforce is one of the most widely deployed CRM platforms in contact center environments. Contact Center Foundry integrates via the **Salesforce REST API**, **Streaming API** (for real-time events), and **Knowledge REST API**.

---

## Authentication

- **OAuth 2.0 JWT Bearer Token Flow** for server-to-server integration
- Connected App registered in Salesforce with minimum required permissions
- Private key stored in Azure Key Vault; public key registered in Salesforce Connected App
- Token refresh handled automatically by the connector

**Required OAuth Scopes:**

| Scope | Reason |
|---|---|
| `api` | REST API access |
| `refresh_token` | Token refresh |
| `wave_api` | Analytics API (for reporting features) |

---

## Read Operations (CRM Context)

At interaction start, the platform retrieves:

```
// Contact lookup by phone or email
GET /services/data/v59.0/query?
  q=SELECT Id, Name, AccountId, Account.Name, Account.Type,
    (SELECT Id, CaseNumber, Subject, Status, CreatedDate 
     FROM Cases WHERE Status != 'Closed' ORDER BY CreatedDate DESC LIMIT 5)
  FROM Contact 
  WHERE Email = '{email}' OR Phone = '{phone}'
  LIMIT 1
```

**Data retrieved:**

| Data | Salesforce Object | Purpose |
|---|---|---|
| Contact | `Contact` | Name, account linkage |
| Account | `Account` | Organisation, type, health |
| Open Cases | `Case` | Current issues |
| Case History | `CaseHistory` | Recent activity |
| Entitlements | `Entitlement` | SLA and service level |
| Assets | `Asset` | Products/services owned |

## Real-Time Events (Streaming API)

For organisations using **Genesys Cloud + Salesforce Open CTI**, the Streaming API provides real-time CRM events:

| CometD Channel | Trigger | Platform Action |
|---|---|---|
| `/topic/NewCase` | New case created | Update agent context panel |
| `/topic/CaseUpdated` | Case status changed | Refresh context |
| `/event/CaseEscalation__e` | Custom escalation event | Alert supervisor |

## Write Operations

### Case Note

```
POST /services/data/v59.0/sobjects/CaseComment/
{
  "ParentId": "{caseId}",
  "CommentBody": "<AI-generated summary>\n\nSources: {knowledge_sources}\n\nGenerated by Contact Center Foundry AI",
  "IsPublished": false
}
```

### Activity Log (Task)

```
POST /services/data/v59.0/sobjects/Task/
{
  "Subject": "AI-Assisted Interaction — {interactionId}",
  "Description": "<Structured interaction summary>",
  "WhatId": "{caseId}",
  "WhoId": "{contactId}",
  "Status": "Completed",
  "ActivityDate": "{today}",
  "Type": "Call"
}
```

## Salesforce Knowledge Integration

Salesforce Knowledge articles are indexed into the knowledge layer:

```
GET /services/data/v59.0/query?
  q=SELECT Id, Title, ArticleBody, Summary, LastModifiedDate, Language
  FROM KnowledgeArticleVersion
  WHERE PublishStatus = 'Online' AND Language = 'en_US'
```

- Supports multiple languages (configured per knowledge source)
- Article categories and data categories preserved for access control filtering
- Incremental sync based on `LastModifiedDate`

---

## Salesforce Open CTI Integration

For organisations deploying via Salesforce Service Cloud:

- Agent Companion can be embedded as a **Salesforce Open CTI softphone** widget
- Single sign-on via Salesforce session
- Agent Companion appears in the Salesforce Service Console sidebar
- Interaction context linked to Salesforce screen pop (case/contact auto-loaded)

## Configuration Reference

```yaml
connector:
  id: salesforce-prod
  type: salesforce
  instance_url: https://yourorg.my.salesforce.com
  auth:
    type: jwt_bearer
    consumer_key_secret: kv://sf-consumer-key
    private_key_secret: kv://sf-jwt-private-key
    username: svc-contactcenter-foundry@yourorg.com
  features:
    context_load: true
    knowledge_index: true
    case_comment_writeback: true
    activity_log: true
    streaming_api: false        # Enable for real-time CRM events
    open_cti: false             # Enable for Service Cloud CTI
  knowledge:
    refresh_interval_hours: 4
    language_filter: ["en_US", "fr"]
```
