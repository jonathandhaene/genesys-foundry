# Zendesk Integration

## Integration Overview

Zendesk is widely used for customer support operations, particularly in technology and e-commerce sectors. Contact Center Foundry integrates with Zendesk via the **Zendesk REST API v2**, **Zendesk Sunshine Events**, and **Zendesk Apps Framework** for the agent companion UI.

---

## Authentication

- **OAuth 2.0** with Zendesk OAuth token
- Dedicated Zendesk agent account with minimum required permissions
- API token stored in Azure Key Vault

**Required Zendesk Scopes:**

| Scope | Reason |
|---|---|
| `tickets:read` | Read ticket data |
| `users:read` | Read user/customer data |
| `help_center:read` | Read knowledge base articles |
| `tickets:write` | Add comments/notes to tickets |

---

## Read Operations (Support Context)

At interaction start:

```
// User lookup by email or phone
GET /api/v2/search.json?
  query=type:user email:{email}

// Recent tickets for user
GET /api/v2/users/{userId}/tickets/requested.json?
  sort_by=created_at&sort_order=desc
```

**Data retrieved:**

| Data | Zendesk Resource | Purpose |
|---|---|---|
| User record | `/api/v2/users/{id}` | Name, organisation, tags |
| Organisation | `/api/v2/organizations/{id}` | Account context |
| Open tickets | `/api/v2/users/{id}/tickets/requested` | Current issues |
| Ticket comments | `/api/v2/tickets/{id}/comments` | Issue history |
| Satisfaction score | `/api/v2/tickets/{id}/satisfaction_rating` | Customer satisfaction history |

---

## Real-Time Events (Zendesk Sunshine Events)

Zendesk Sunshine (Events Platform) supports outbound webhooks:

| Trigger | Event | Platform Action |
|---|---|---|
| Ticket created | `ticket.created` | Alert agent if customer is on active call |
| Ticket priority escalated | `ticket.priority_changed` | Update agent context |
| SLA breach warning | `ticket.sla_breach_warning` | Alert supervisor |

## Write Operations

### Internal Note on Ticket

```
POST /api/v2/tickets/{id}.json
{
  "ticket": {
    "comment": {
      "body": "AI Interaction Summary ({datetime}):\n\n{summary}\n\nTopics discussed: {topics}\n\nKnowledge sources used: {sources}\n\n[Generated by Contact Center Foundry AI — Interaction: {interactionId}]",
      "public": false
    }
  }
}
```

### New Ticket from Interaction

If the agent creates a new ticket during an interaction:

```
POST /api/v2/tickets.json
{
  "ticket": {
    "subject": "<AI-extracted subject>",
    "comment": {
      "body": "<AI-generated issue description>"
    },
    "requester_id": "{zendesk_user_id}",
    "tags": ["ai_assisted", "{channel}", "{ai_detected_topic}"],
    "priority": "<AI-assessed priority>",
    "custom_fields": [
      { "id": 123, "value": "{interactionId}" }
    ]
  }
}
```

## Help Center Knowledge Integration

Zendesk Help Center articles (internal and external) are indexed into the knowledge layer:

```
GET /api/v2/help_center/articles.json?
  locale=en-us&
  sort_by=updated_at&
  per_page=100
```

- Supports both internal (agent-facing) and external (customer-facing) articles
- Article visibility labels respected at query time
- Section hierarchy preserved for filtering
- Multilingual articles indexed with language tag

---

## Zendesk Apps Framework Integration

The Agent Companion UI can be embedded as a **Zendesk App** within the agent workspace:

- Installed from Zendesk Marketplace (private listing) or sideloaded for enterprise
- Single sign-on via Zendesk agent session
- Appears in the Zendesk Support sidebar
- Auto-triggers on ticket load or new conversation assigned

## Configuration Reference

```yaml
connector:
  id: zendesk-prod
  type: zendesk
  subdomain: yourorg              # yourorg.zendesk.com
  auth:
    type: oauth_token
    token_secret: kv://zendesk-oauth-token
    email_secret: kv://zendesk-integration-email
  features:
    context_load: true
    knowledge_index: true
    ticket_note_writeback: true
    ticket_create: true
    sunshine_events: false         # Enable for real-time webhook events
    apps_framework: false          # Enable for in-app agent companion
  knowledge:
    refresh_interval_hours: 4
    include_community: false       # Set true to index community posts
    locale_filter: ["en-us", "fr", "de"]
```
